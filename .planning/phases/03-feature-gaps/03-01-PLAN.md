   - Status: "no deadline" (no deadline set), "completed" (progress >= 100%), "overdue" (days < 0), "at-risk" (days <= 30 AND progress < 50%), "on-track" (otherwise)

3. Timeline visualization (D-12: horizontal progress bars, NOT Gantt chart):
   - Each goal renders as a horizontal bar with:
     - Goal name on the left
     - Progress bar (width = progress %, color = goal.color)
     - Deadline indicator on the right: "vence em X dias" or "vencido há X dias"
     - Status badge: "Concluído" (green), "No prazo" (blue), "Atenção" (amber), "Vencido" (red), "Sem prazo" (gray)
   - Use existing design tokens: `bg-surface border border-surface-border p-card-padding`
   - Progress bar uses `h-2.5 bg-muted rounded-full overflow-hidden` pattern (same as BudgetCard)

4. Highlight overdue/at-risk goals (D-12):
   - Overdue: red left border (`border-l-4 border-red-500`), red status badge
   - At-risk (<=30 days, <50%): amber left border (`border-l-4 border-amber-500`), amber status badge
   - On-track: blue left border (`border-l-4 border-blue-500`), blue status badge
   - Completed: green left border (`border-l-4 border-emerald-500`), green status badge
