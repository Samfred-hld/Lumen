    - BOM detection: UTF-8 BOM (EF BB BF) → 'utf-8'; UTF-16LE BOM (FF FE) → 'utf-16le'; UTF-16BE BOM (FE FF) → 'utf-16be'
    - UTF-8 validation: Valid multi-byte sequences pass; invalid continuation bytes → fallback to Windows-1252 or ISO-8859-1
    - Windows-1252 heuristic: Bytes 0x80-0x9F present → 'windows-1252'; absent → 'iso-8859-1'
    - detectSeparator: Identifies comma, semicolon, and tab separators from sample text; handles quoted text that contains separators
    - parseCSVText: Parses simple CSV; handles quoted fields with commas inside; escaped quotes "" inside quoted fields; CRLF and LF line endings; trims trailing empty rows
    - stripBOM: Removes U+FEFF from beginning of text; does NOT remove mid-text U+FEFF
    - detectDateFormat: Detects DMY (dd/mm/yyyy) — the Brazilian default; MDY (mm/dd/yyyy); YMD (yyyy-mm-dd); handles mixed samples with voting; ambiguous (both ≤12) defaults to DMY
    - normalizeDate: DMY input → ISO output; MDY input → ISO output; YMD input → ISO output; 2-digit years (≤30 → '20xx', >30 → '19xx'); already-ISO dates pass through unchanged; null input → null
    - validateDateRange: Valid date in range → no warning; date before 2000 → warning "Data muito antiga"; date >1 year in future → warning "Data no futuro"; null/NaN → warning "Data inválida"
  </behavior>
