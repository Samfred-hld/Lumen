  <action>
    Modify `src/lib/store/settings.js`:
    - The existing `setTheme(t)` function stores the value directly and applies `data-theme` + `.dark` class. Extend it to handle the `'auto'` value:
      - When `t === 'auto'`: store `'auto'` in localStorage, but determine the actual theme from `window.matchMedia('(prefers-color-scheme: dark)').matches`
      - Apply `data-theme` and `.dark` class based on the resolved value (dark or light)
      - When `t === 'light'` or `t === 'dark'`: behave as before
    - `getTheme()` already returns the stored value — no change needed (it will now return 'auto' in addition to 'light'/'dark')

    Create `src/hooks/useThemePreference.js`:
    - Import `getTheme` and `setTheme` from `@/lib/store` (the barrel export)
    - Initialize `preference` state from `getTheme()` (returns 'light', 'dark', or 'auto')
    - Create `applyTheme(pref)` callback:
      - If `pref === 'dark'` → set `data-theme="dark"` and add `.dark` class on `document.documentElement`
      - If `pref === 'light'` → set `data-theme="light"` and remove `.dark` class
      - If `pref === 'auto'` → check `window.matchMedia('(prefers-color-scheme: dark)').matches` and apply dark or light accordingly
      - Call `setTheme(pref)` to persist
    - In useEffect with `[preference]` dependency:
      - Call `applyTheme(preference)`
      - If `preference === 'auto'`: add a `change` event listener on `window.matchMedia('(prefers-color-scheme: dark)')` that calls `applyTheme('auto')` when the system preference changes
      - Return cleanup function to remove the listener
    - Export: `{ preference, setPreference }` where `setPreference` is just the state setter

    Add FOUC prevention script to `index.html`:
    - Add an inline `<script>` tag BEFORE the `<div id="root">` and the module script
    - The script must:
      1. Read the theme preference from localStorage using the same key pattern as `getLocal('theme')` — the key is `{getPrefix()}theme` where prefix is `rattio_{userId}_`. Since the script runs before React, use the fallback pattern: try `localStorage.getItem('rattio_*_theme')` by iterating localStorage keys, or fall back to `localStorage.getItem('rattio_theme')` for the non-user-prefixed case
      2. Simpler approach: read ALL localStorage keys matching `/rattio_.*theme/` and use the first match. If none found, check `'rattio_theme'` as legacy key.
      3. If the resolved value is 'dark' OR ('auto' AND `matchMedia('(prefers-color-scheme: dark)').matches`): set `document.documentElement.setAttribute('data-theme', 'dark')` and `document.documentElement.classList.add('dark')`
      4. Otherwise: set `data-theme="light"`
    - Wrap in try/catch to prevent any errors from blocking page load
  </action>
