## Interaction Patterns

### PWA Install Prompt (D-03)

- **Trigger:** `beforeinstallprompt` event fires on mobile
- **Display:** Custom banner at bottom of screen (not browser default)
- **Position:** Fixed bottom, above mobile nav (`bottom-[64px]` — matches `mobile-nav-height`)
- **Behavior:** Show once per session. "Agora não" dismisses for session. Successful install hides permanently.
- **Animation:** `animate-slide-in-right` (existing Tailwind keyframe)
- **Styling:** `bg-surface border border-surface-border shadow-lg rounded-lg p-card-padding`

### Offline Detection & Queue (D-01, D-04)

- **Detection:** `navigator.onLine` + `online`/`offline` events
- **Status bar:** Fixed top bar below header, `bg-warning/10 text-warning` when offline, `bg-success/10 text-success` when restored
- **Mutation queue:** localStorage array of pending mutations (table, action, data, timestamp)
- **Sync behavior:** On `online` event, process queue sequentially. Show progress indicator. Last-write-wins with timestamp (D-04).
- **Visual feedback:** Sync status icon in header — spinning when syncing, checkmark when done, exclamation when failed

### Profile Page Layout (D-05)

- **Structure:** Sidebar navigation with sections (Informações pessoais, Segurança, Sessões)
- **Sections:**
  1. Informações pessoais: email display + update form
  2. Segurança: password change form
  3. Sessões: active session display (device, last active)
  4. Zona de perigo: account deletion (red-accented section)
- **Danger zone styling:** `border-danger/30 bg-danger/5` with destructive button

### Dark Mode Scheduling (D-10)

- **Options:** Three radio buttons or segmented control: "Claro" / "Escuro" / "Automático (sistema)"
- **"Auto" behavior:** Listen to `prefers-color-scheme` media query. Apply `.dark` class when dark preferred. Manual selection overrides media query.
- **Persistence:** Store preference as `"light"` / `"dark"` / `"auto"` in settings
- **Transition:** Use existing `transition-colors duration-200` on `<html>` for smooth theme switch

### Backup/Restore (D-08, D-09, D-11)

- **Backup flow:** Click "Fazer backup" → JSON file downloads to device (D-11)
- **Backup content:** All entities — transactions, budgets, goals, cards, rules, templates, settings
- **Restore flow:** Click "Restaurar dados" → file picker (`.json` only) → validate schema + show row count summary (D-09) → confirm dialog → batch import with progress bar
- **Validation:** Check JSON structure matches expected schema. Show summary: "N transações, N orçamentos, N metas, N cartões"
- **Progress:** Determinate progress bar during import. Indeterminate if row count unknown.

### Accessibility (WCAG 2.1 AA)

- **Focus traps:** All modals (install banner dismiss, restore confirm, account deletion) trap focus
- **Touch targets:** Minimum 44px for all interactive elements. Primary CTAs 48px.
- **ARIA:** All new components use appropriate ARIA roles, labels, live regions
- **Offline status:** `role="status" aria-live="polite"` on offline bar
- **Sync status:** `role="status" aria-live="polite"` on sync indicator
- **Print:** `@media print` hides interactive elements, ensures readable layout
