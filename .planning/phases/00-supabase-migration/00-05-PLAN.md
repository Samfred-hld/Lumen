# Plan 00-05: Implement Real-Time Subscriptions (Supabase Realtime)

**Objective:** Replace Base44 subscription pattern with Supabase Realtime channels, creating a custom `useSupabaseRealtime` hook that keeps React Query caches fresh.

**Context:** The app currently subscribes to entity changes via `base44.entities.Transaction.subscribe(callback)`. Supabase Realtime uses PostgreSQL logical replication via channels. This plan creates the real-time bridge and wires it into all data hooks.

**Success criteria:**
- [ ] `useSupabaseRealtime(table, queryKey)` custom hook created
- [ ] Hook subscribes to `postgres_changes` on the specified table
- [ ] Changes invalidate the correct React Query cache key
- [ ] Channel lifecycle managed (subscribe on mount, unsubscribe on unmount)
- [ ] Adding a transaction in one tab updates all other tabs in <3 seconds
- [ ] All 4 primary data hooks wired to real-time

**must_haves:**
- Real-time subscriptions keep all tabs in sync
- Channel cleanup on unmount prevents memory leaks
- React Query invalidation on every change event

## Task 1: Create useSupabaseRealtime hook
- Create `src/hooks/useSupabaseRealtime.js`:
  ```js
  import { useEffect } from 'react'
  import { useQueryClient } from '@tanstack/react-query'
  import { supabase } from '../api/supabaseClient'

  export function useSupabaseRealtime(table, queryKey) {
    const queryClient = useQueryClient()

    useEffect(() => {
      const channel = supabase
        .channel(`${table}-changes`)
        .on('postgres_changes', {
          event: '*',
          schema: 'public',
          table: table
        }, () => {
          queryClient.invalidateQueries({ queryKey: [queryKey] })
        })
        .subscribe()

      return () => {
        supabase.removeChannel(channel)
      }
    }, [table, queryKey, queryClient])
  }
  ```
