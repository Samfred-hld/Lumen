# Plan 00-01: Install Supabase SDK & Remove Base44 SDK

**Objective:** Add `@supabase/supabase-js` to the project, remove all Base44 SDK dependencies, create the Supabase client initialization module, and clean up the Vite config.

**Context:** Base44 is a proprietary BaaS the app is tightly coupled to. This plan begins the migration by swapping the SDK dependency and establishing the Supabase client as the new data-access foundation. The Base44 SDK (`@base44/sdk`, `@base44/vite-plugin`) and their config must be completely removed.

**Success criteria:**
- [ ] `npm install @supabase/supabase-js` succeeds
- [ ] `@base44/sdk` and `@base44/vite-plugin` removed from `package.json`
- [ ] `src/api/supabaseClient.js` exports a configured Supabase client using `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`
- [ ] `vite.config.js` no longer imports or uses `@base44/vite-plugin`
- [ ] `.env.example` updated with Supabase variables, Base44 variables removed
- [ ] `npm run build` succeeds (app may not function yet, but build passes)

**must_haves:**
- Supabase client singleton created and exported
- Zero Base44 imports remain in package.json and vite.config.js
- Build succeeds with no Base44 references

<tasks>

## Task 1: Install Supabase SDK
- Run `npm install @supabase/supabase-js`
- Run `npm uninstall @base44/sdk @base44/vite-plugin`
- Verify `package.json` has `@supabase/supabase-js` in dependencies
- Verify `@base44/sdk` and `@base44/vite-plugin` are absent
- Commit: `chore(00-01): install @supabase/supabase-js, remove Base44 SDK`

## Task 2: Create Supabase client module
- Create `src/api/supabaseClient.js`:
  ```js
  import { createClient } from '@supabase/supabase-js'

  const supabaseUrl = import.meta.env.VITE_SUPABASE_URL
  const supabaseAnonKey = import.meta.env.VITE_SUPABASE_ANON_KEY

  if (!supabaseUrl || !supabaseAnonKey) {
    throw new Error('Missing VITE_SUPABASE_URL or VITE_SUPABASE_ANON_KEY environment variables')
  }

  export const supabase = createClient(supabaseUrl, supabaseAnonKey)
  ```
- Commit: `feat(00-01): create Supabase client module (src/api/supabaseClient.js)`

## Task 3: Clean Vite config and environment
- Update `vite.config.js`: remove `import base44Plugin from '@base44/vite-plugin'` and the plugin registration
- Update `.env.example`: remove `VITE_BASE44_*` variables, add `VITE_SUPABASE_URL=` and `VITE_SUPABASE_ANON_KEY=`
- Update `src/webinit.js`: remove Base44 initialization, import `supabase` from `./api/supabaseClient.js` instead
- Run `npm run build` and verify no Base44-related errors
- Commit: `chore(00-01): remove Base44 from Vite config, update env template`
