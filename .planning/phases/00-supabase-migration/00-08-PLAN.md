# Plan 00-08: Create Data Migration Script

**Objective:** Build a one-shot migration tool that exports all user data from Base44, transforms it to the Supabase schema, and imports it with row count validation.

**Context:** Existing users have data in Base44 that must be preserved. This plan creates a script that reads from Base44, normalizes field names, adds `user_id` columns, and upserts into Supabase with conflict resolution. The script validates completeness by comparing row counts.

**Success criteria:**
- [ ] Script exports all 8 entity types from Base44
- [ ] Data transformed: field names normalized, `user_id` added, dates converted to ISO
- [ ] Import uses upsert with conflict resolution on primary keys
- [ ] Row count validation: Base44 count == Supabase count for each entity
- [ ] Script exits with code 0 only when all counts match
- [ ] Script is idempotent (can be re-run safely)

**must_haves:**
- All Base44 data successfully migrated to Supabase
- 100% row count match for all entities
- Script handles errors gracefully with clear messages

<tasks>

## Task 1: Create export and transform logic
- Create `scripts/migrate-base44-to-supabase.js`:
  - Read Base44 credentials from environment variables
  - Initialize Base44 SDK to export all entities
  - Export transactions, budgets, goals, cards, rules, templates, user_configs, settings
  - Transform: normalize field names to snake_case, convert date strings to ISO, add `user_id` field
  - Handle Base44's array-based entity storage → PostgreSQL row-per-entity
- Add script entry to `package.json`: `"migrate:base44": "node scripts/migrate-base44-to-supabase.js"`
- Commit: `feat(00-08): create Base44 export and transform logic`

## Task 2: Create import and validation logic
- Initialize Supabase client with service_role key (full access, bypass RLS for migration)
- For each entity type:
  - Batch insert using `supabase.from(table).upsert(rows, { onConflict: 'id' })`
  - Count rows in Supabase: `supabase.from(table).select('*', { count: 'exact', head: true })`
  - Compare with Base44 export count
  - Report mismatches with specific entity names and counts
- Exit with code 1 if any entity count doesn't match
- Commit: `feat(00-08): create Supabase import and row count validation`

## Task 3: Add dry-run and error handling
- Add `--dry-run` flag: exports and transforms but doesn't import
- Add detailed logging: entity name, row count, duration for each step
- Handle network errors with retry (3 attempts, exponential backoff)
- Handle duplicate key conflicts gracefully (upsert handles most cases)
- Test with a small subset of data first
- Commit: `feat(00-08): add dry-run mode and error handling`

</tasks>
