# Plan 00-07: Migrate Cron Functions to Supabase Edge Functions

**Objective:** Convert the 5 Base44 cron functions to Supabase Edge Functions running on the Deno runtime with `pg_cron` scheduling.

**Context:** The app has 5 serverless cron functions in `base44/functions/` that generate recurring transactions, salary entries, recurring budgets, budget alerts, and invoice reminders. These need to be rewritten as Supabase Edge Functions using Deno + TypeScript.

**Success criteria:**
- [ ] 5 edge functions deployed to Supabase
- [ ] `generate-recurring` creates recurring transactions for all users on schedule
- [ ] `generate-salary` creates salary entries on schedule
- [ ] `generate-recurring-budgets` creates budget entries for recurring budgets
- [ ] `send-budget-alert` sends notifications when budgets exceed thresholds
- [ ] `send-invoice-reminder` sends reminders for upcoming card due dates
- [ ] All functions use `pg_cron` for scheduling
- [ ] Original `base44/functions/` directory can be removed

**must_haves:**
- All 5 cron functions operational on Supabase Edge Functions
- Functions use Deno runtime and Supabase service role for database access
- Scheduling configured via pg_cron

<tasks>

## Task 1: Create generate-recurring and generate-salary edge functions
- Create `supabase/functions/generate-recurring/index.ts`:
  - Deno runtime entrypoint, imports from `jsr:@supabase/functions-js/edge-runtime.d.ts`
  - Query all active recurring templates from `templates` table
  - For each template due today: insert a new transaction
  - Use service_role key for admin database access
- Create `supabase/functions/generate-salary/index.ts`:
  - Check if today is salary day (configurable, default last business day)
  - Insert salary transaction for each user with salary config in `user_configs`
- Commit: `feat(00-07): create generate-recurring and generate-salary edge functions`

## Task 2: Create generate-recurring-budgets, send-budget-alert, send-invoice-reminder
- Create `supabase/functions/generate-recurring-budgets/index.ts`:
  - Query budgets where `isRecurring = true` and month is current
  - Create budget entries for the current month if missing
- Create `supabase/functions/send-budget-alert/index.ts`:
  - Query all budgets and compare `limit` vs actual spending
  - Send alert (console.log for now, email via Resend later) when >80% used
- Create `supabase/functions/send-invoice-reminder/index.ts`:
  - Query cards where `dueDay` is within next 3 days
  - Send reminder (console.log for now) for each upcoming due date
- Commit: `feat(00-07): create budget, alert, and invoice edge functions`

## Task 3: Configure scheduling and deploy
- Create `supabase/functions/deno.json` with import map if needed
- Deploy all 5 functions: `supabase functions deploy generate-recurring` etc.
- Configure pg_cron schedules:
  - `generate-recurring`: daily at 00:00
  - `generate-salary`: monthly on configured day
  - `generate-recurring-budgets`: monthly on the 1st
  - `send-budget-alert`: daily at 08:00
  - `send-invoice-reminder`: daily at 08:00
- Test by invoking each function manually: `supabase functions invoke generate-recurring`
- Remove `base44/functions/` directory
- Commit: `feat(00-07): deploy edge functions with pg_cron scheduling`
