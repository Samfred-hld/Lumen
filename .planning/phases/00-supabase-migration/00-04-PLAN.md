# Plan 00-04: Rewrite Data Hooks for Supabase

**Objective:** Replace all Base44 entity CRUD operations in data hooks with Supabase PostgreSQL queries using `supabase-js`.

**Context:** The app's data layer is built on `base44.entities.*` (Transaction, Budget, Goal, Card, Rule, Template, Setting, UserConfig). This plan rewrites every data hook to use Supabase's `from().select()`, `.insert()`, `.update()`, `.delete()` methods with proper query building.

**Success criteria:**
- [ ] `useTransactions()` returns data from `supabase.from('transactions')` with filtering, sorting, date ranges
- [ ] `useBudgets()` returns data from `supabase.from('budgets')` with month filtering
- [ ] `useGoals()` returns data from `supabase.from('goals')`
- [ ] `useCards()` returns data from `supabase.from('cards')`
- [ ] CRUD operations (create, update, delete) work on all entities
- [ ] Zero `base44.entities.*` references remain in any hook file
- [ ] React Query cache invalidation works correctly

**must_haves:**
- All 4 primary data hooks return live data from Supabase
- Filtering, sorting, date range queries work as before
- Create/update/delete operations commit to Supabase

<tasks>

## Task 1: Rewrite useTransactions hook
- Read current `src/hooks/useTransactions.js` (or `useData.js` transaction-specific code)
- Replace `base44.entities.Transaction.list('-date', limit)` with `supabase.from('transactions').select('*').order('date', { ascending: false }).limit(limit)`
- Replace `base44.entities.Transaction.filter({...})` date range queries with `.gte('date', ...).lte('date', ...)`
- Replace `base44.entities.Transaction.create(data)` with `.insert(data).select().single()`
- Replace `base44.entities.Transaction.update(id, data)` with `.update(data).eq('id', id).select().single()`
- Replace `base44.entities.Transaction.delete(id)` with `.delete().eq('id', id)`
- Use React Query `useQuery`, `useMutation` from `@tanstack/react-query`
- Commit: `feat(00-04): rewrite useTransactions hook for Supabase`

## Task 2: Rewrite useBudgets and useGoals hooks
- Rewrite `useBudgets()`: `supabase.from('budgets').select('*').eq('month', ...)`

- Add create/update/delete mutations for both
- Handle `.eq('user_id', user.id)` filter automatically (RLS handles this, but explicit for clarity)
- Commit: `feat(00-04): rewrite useBudgets and useGoals hooks for Supabase`
