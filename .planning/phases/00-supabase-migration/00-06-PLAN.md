# Plan 00-06: Replace Store Layer for Supabase

**Objective:** Rewrite `src/lib/store.js` barrel and all store modules to use Supabase queries instead of Base44 entity operations.

**Context:** The `src/lib/store/` directory contains modules for cards, rules, templates, and settings that use `base44.entities.*` for CRUD. These need to use Supabase queries directly. The localStorage fallback pattern should be removed since Supabase is always available.

**Success criteria:**
- [ ] `src/lib/store.js` barrel re-exports all store modules correctly
- [ ] `src/lib/store/cards.js` uses Supabase queries
- [ ] `src/lib/store/rules.js` uses Supabase queries
- [ ] `src/lib/store/templates.js` uses Supabase queries
- [ ] `src/lib/store/settings.js` uses Supabase queries
- [ ] localStorage fallback removed from all store modules
- [ ] `Promise.allSettled` pattern replaced with single Supabase queries
- [ ] Zero `base44.entities.*` references in store directory

**must_haves:**
- All store modules operational on Supabase
- No localStorage fallback (Supabase is always-on with offline queue in Phase 4)
- Helper function prefix logic updated for Supabase client access
