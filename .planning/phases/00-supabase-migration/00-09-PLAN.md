# Plan 00-09: Configure Vercel Deployment

**Objective:** Set up production and preview deployments on Vercel with Supabase environment variables and SPA rewrite rules.

**Context:** The app currently deploys through Base44's hosting. This plan configures Vercel as the new deployment target with proper SPA routing, environment variables for Supabase, and clean removal of Base44 deployment config.

**Success criteria:**
- [ ] `vercel.json` created with SPA rewrite rules
- [ ] `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` added to Vercel environment
- [ ] `VITE_BASE44_*` environment variables removed
- [ ] `npm run build` produces correct `dist/` with Supabase client
- [ ] Preview deployments configured for branches
- [ ] App accessible at public Vercel URL with Supabase backend

**must_haves:**
- Production deployment succeeds on Vercel
- SPA routing works (all routes serve index.html)
- Supabase environment variables correctly injected at build time

<tasks>

## Task 1: Create vercel.json with SPA config
- Create `vercel.json`:
  ```json
  {
    "rewrites": [
      { "source": "/((?!api/).*)", "destination": "/index.html" }
    ],
    "buildCommand": "npm run build",
    "outputDirectory": "dist",
    "framework": "vite"
  }
  ```
- Remove any Base44-specific deployment config files
- Commit: `feat(00-09): create vercel.json with SPA rewrite rules`

## Task 2: Update environment configuration
- Update `.env.example` with clear documentation:
  ```env
  VITE_SUPABASE_URL=https://your-project.supabase.co
  VITE_SUPABASE_ANON_KEY=your-anon-key
  ```
- Add `.vercel` to `.gitignore` if not present
- Remove any Base44 environment variable references
- Verify `npm run build` reads from `VITE_*` variables correctly
- Commit: `chore(00-09): update environment config for Vercel + Supabase`

## Task 3: Verify build and deployment readiness
- Run `npm run build` and inspect `dist/` output:
  - `index.html` exists with correct asset references
  - No Base44 chunks in bundle (check with `rg "base44" dist/`)
  - Supabase client bundled correctly
- Verify all routes work locally: `/login`, `/signup`, `/dashboard`, `/transactions`
- Document deployment steps in terminal output or a brief note
- Commit: `docs(00-09): verify build and document deployment steps`

</tasks>
