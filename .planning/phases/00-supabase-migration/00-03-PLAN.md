# Plan 00-03: Migrate Authentication (Base44 Auth → Supabase Auth)

**Objective:** Replace `AuthContext.jsx` to use Supabase Auth exclusively. Add login/signup pages with email/password and password reset flows.

**Context:** The app currently uses `base44.auth.me()`, `base44.auth.logout()`, and `base44.auth.redirectToLogin()` for authentication. This plan replaces all auth calls with Supabase Auth equivalents and adds proper login/signup UI pages.

**Success criteria:**
- [ ] `AuthContext.jsx` uses `supabase.auth.getUser()`, `supabase.auth.signOut()`, `supabase.auth.onAuthStateChange()`
- [ ] Login page with email/password form exists and works
- [ ] Signup page with email/password/name form exists and works
- [ ] Password reset flow works via Supabase
- [ ] Email verification flow configured
- [ ] `createAxiosClient` calls for app-level auth removed
- [ ] Zero `base44.auth.*` references remain

**must_haves:**
- Users can sign up, log in, reset password via Supabase Auth
- AuthContext no longer imports from Base44
- Auth state persists across page reloads
