# Plan 00-02: Create PostgreSQL Schema (8 entities → tables)

**Objective:** Create Supabase migration scripts mapping all 8 Base44 entities to PostgreSQL tables with Row Level Security (RLS) policies.

**Context:** The app currently stores all data in Base44's proprietary entity store. This plan creates the Supabase PostgreSQL schema with 8 tables matching the existing entity structure, plus `user_id` columns for multi-tenancy and RLS policies ensuring users can only access their own data.

**Success criteria:**
- [ ] Migration script creates 8 tables: `transactions`, `budgets`, `goals`, `cards`, `rules`, `templates`, `user_configs`, `settings`
- [ ] All tables have `user_id` column (UUID, references `auth.users`)
- [ ] RLS enabled on all tables with policy: `auth.uid() = user_id`
- [ ] Column types match existing entity field types (text, numeric, boolean, timestamptz, jsonb)
- [ ] Migration applies successfully via `supabase db push` or migration runner

**must_haves:**
- All 8 tables created with correct columns
- RLS policies prevent cross-user data access
- `user_id` foreign key to `auth.users` on every table

<tasks>

## Task 1: Create migration for core financial tables
- Create `supabase/migrations/001_create_tables.sql` with:
  - `transactions` table: id (uuid PK, default gen_random_uuid()), user_id (uuid FK → auth.users), description, value (numeric), date (timestamptz), category, paymentMethod, type (income/expense), isRecurring (boolean), recurringId, card, installments, isPaid, createdAt, updatedAt
  - `budgets` table: id, user_id, category, limit (numeric), month, isRecurring (boolean), createdAt, updatedAt
  - `goals` table: id, user_id, name, targetValue (numeric), currentValue (numeric), progressMode, deadline (date), color, description, investmentType, createdAt, updatedAt
- Add `CREATE INDEX` statements on user_id for both tables
- Commit: `feat(00-02): create core tables (transactions, budgets, goals)`

## Task 2: Create migration for supporting tables
- Add to migration file or create `002_create_supporting_tables.sql`:
  - `cards` table: id, user_id, name, color, limit (numeric), closingDay (int), dueDay (int), brand, createdAt, updatedAt
  - `rules` table: id, user_id, keyword, category, createdAt
  - `templates` table: id, user_id, description, value (numeric), category, paymentMethod, type, createdAt
  - `user_configs` table: id, user_id, key, value (jsonb), createdAt, updatedAt
  - `settings` table: id, user_id, key, value (jsonb), createdAt, updatedAt
- Add indexes on user_id + key for user_configs and settings
- Commit: `feat(00-02): create supporting tables (cards, rules, templates, user_configs, settings)`

## Task 3: Add RLS policies
- Enable RLS on all 8 tables: `ALTER TABLE ... ENABLE ROW LEVEL SECURITY`
- Create policy for each table: `CREATE POLICY "Users can only access their own data" ON ... FOR ALL USING (auth.uid() = user_id)`
- Also add insert policy: `WITH CHECK (auth.uid() = user_id)`
- Apply migration and verify tables exist with correct RLS
- Commit: `feat(00-02): add RLS policies to all tables`

</tasks>
